# Data dictionary

Database `tecidos` (MySQL 8.4). Generated by `scripts/gerar_dicionario.py`: types and keys come from `schema.sql`, row counts and % nulls from the data files. Intentional imperfections are flagged and explained in [imperfeicoes.md](imperfeicoes.md). Table and column names are in Portuguese, as in the database; the diagrams are in [diagrama_er.md](diagrama_er.md).

**Time zones:** transactional data in local time (America/Sao_Paulo); tracking in UTC; media metrics in the account time zone.
