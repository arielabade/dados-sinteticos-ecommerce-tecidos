# Tecelã Tecidos: synthetic data for a fabric e-commerce store

[![Tecelã Tecidos data model: overview and the diagrams of the 7 areas](docs/diagramas/modelo_de_dados_one_pager.svg)](docs/diagramas/modelo_de_dados_one_pager.svg)

<sub>The whole model on one page. Click to zoom in, or download it as [PNG](docs/diagramas/modelo_de_dados_one_pager.png) or [PDF](docs/diagramas/modelo_de_dados_one_pager.pdf). Each area's detailed diagram is in [`docs/diagrama_er.md`](docs/diagrama_er.md).</sub>

**Tecelã Tecidos** is a **fictitious** Brazilian online fabric store that sells to hobby sewists, seamstresses, studios and small garment makers. This repository generates the store's complete database from **Oct 1, 2023 to Oct 13, 2026**:

- catalog, prices and daily inventory;
- customers, orders, payments, shipping and returns;
- website tracking (GA4 sessions and events via server-side GTM, sends to the Meta CAPI);
- paid media (Meta, Google and TikTok Ads, down to the ad and keyword level), affiliates, CRM and attribution;
- MMM layer: media by state, retail calendar and geographic tests.

The goal is to practice marketing and e-commerce analytics on data that looks like production: CAC, ROAS, MER, LTV, funnels, RFM, demand forecasting, churn and media incrementality.

Everything is made up: products, suppliers, campaigns, people, e-mails (`example` domain), CPFs, phone numbers and addresses. Personal data was generated from scratch with Faker `pt_BR` (CPFs and CNPJs, the Brazilian personal and company IDs, have the official format but deliberately invalid check digits), and `scripts/varredura_pii.py` checks that no real personal data ended up in the database.

**Ready-to-use dataset on Kaggle:** [ecommerce-sintetico-midia-paga](https://www.kaggle.com/datasets/arielabade/ecommerce-sintetico-midia-paga), with the 44 tables in Parquet and a consolidated media table (CPM, CTR, CPC, ROAS).

> Table and column names are in Portuguese, as in the database (`pedidos` = orders, `clientes` = customers, `sessoes` = sessions). The [data dictionary](docs/dicionario_dados.md) describes every column in English.

## How to run

Requirements: Python 3.11+, Docker with Compose v2 and ~25 GB of free disk (CSVs + MySQL volume + dbt temporary files).

```bash
make ambiente     # creates .venv and installs requirements.txt
make dados        # generates the CSVs in data/csv (~13 min; ESCALA=0.05 make dados for a ~1 min sample)
make mysql        # starts MySQL and loads the CSVs; it only becomes "healthy" when the load finishes
make dbt          # dbt models and tests, inside a container
make validar      # integrity checks and checks of the expected imperfections
make notebooks    # runs the 5 notebooks
make dicionario   # regenerates docs/dicionario_dados.md
make diagramas    # regenerates docs/diagramas/ from schema.sql
```

`make tudo` runs the sequence from `dados` to `notebooks`. `make limpar` stops MySQL and deletes its volume (the CSVs stay).

- **Connection:** `localhost:3336`, database `tecidos`, user `analista` / password `analista123` (root: `tecidos_root`). To change them, copy `.env.example` to `.env`.
- **Memory:** InnoDB uses 1 GB by default (`MYSQL_BUFFER_POOL`). With little free RAM, run dbt with `--threads 1`.
- **Notebook charts:** they are exported as PNG by `kaleido`, which needs Chrome. Run `plotly_get_chrome` once or point `BROWSER_PATH` to an installed Chrome/Chromium. Without Chrome, charts come out as interactive HTML, which GitHub does not display.
- **Data dictionary without the database:** `python scripts/gerar_dicionario.py --parquet <folder>` reads types and keys from `schema.sql` and statistics from one Parquet file per table.

## Notebooks

| Notebook | Question |
|---|---|
| `01_previsao_demanda_receita` | How many orders and how much revenue to expect in the coming months, including Black Friday 2026? |
| `02_churn_propensao_recompra` | Which customers are most likely not to buy again within 90 days, and how much is it worth acting on them? |
| `03_segmentacao_clientes` | What customer groups exist based on purchase behavior, and do they match the type declared at registration? |
| `04_ltv_preditivo` | How much will each customer generate in 12 months, and what is the maximum CAC per channel? |
| `05_incrementalidade_mmm` | How many orders does each media channel really drive? Pause test + calibrated MMM, compared with the answer key. |

## Business context

- **Customers:** hobby sewists, seamstresses, studios and garment makers, both individuals and companies. Fabric is sold by the meter or by the roll.
- **Seasonality:** back to school, Consumer Day (Mar 15), Mother's Day, Seamstress Day (May 25), the June festivals (chita and plaid fabrics), Black Friday and Christmas. Linen and viscose sell more in hot weather.
- **Media:** Meta (prospecting, remarketing, seasonal campaigns and tests) and Google (brand and generic Search, Shopping, PMax, Demand Gen). All Meta prospecting was paused from Aug 4 to 24, 2025, as an incrementality test.
- **Tracking:** server-side GTM with Consent Mode v2; the purchase fires from both the browser and the server. The problems this causes are in `docs/imperfeicoes.md`.
